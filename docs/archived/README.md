# Archived Documentation

These documents describe the project's original ES6 migration strategy using a bridge pattern. That strategy has been superseded by the [Modernization Roadmap](../MODERNIZATION_ROADMAP.md).

These files are kept for historical context. They describe approaches and patterns that are no longer being actively pursued. The bridge pattern is deprecated and will be removed.

**Do not follow these documents for new development work.**

## Contents

- `ROADMAP.md` - Original 9-phase bridge migration roadmap
- `ES6_MIGRATION_PLAN.md` - Detailed ES6 migration plan via bridge pattern
- `BRIDGE_ARCHITECTURE.md` - Bridge pattern architecture explanation
- `BRIDGE_INITIALIZATION_PATTERN.md` - Bridge timing/initialization fix
- `ES6_GAMEJS_MAPPING.md` - Legacy game.js to ES6 module mapping
- `PHASE2_TESTING_PLAN.md` - Phase 2 bridge testing plan
- `USAGE_REDUCTION.md` - Bridge module removal tracking
- `es6-improvements/` - ES6 optimization techniques explored during bridge migration
